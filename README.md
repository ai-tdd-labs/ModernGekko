# ModernGekko

A runtime for GameCube/Wii recomps.

This integration keeps the public ExpansionPak projects as its base and applies
the strict-native, diagnostics, replay, and enhancement work as explicit layers
above them. See [docs/UPSTREAM_LAYERING.md](docs/UPSTREAM_LAYERING.md) before
updating ModernGekko, RecompCore, or DolRecomp.
